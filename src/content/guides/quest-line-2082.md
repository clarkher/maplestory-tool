# 楓之谷經典版木妖好可怕系列任務攻略：6 個任務怎麼接、去哪打、拿什麼

楓之谷經典版勇士之村的**義安**怕木妖，弓箭手村的**布魯斯**在找失散的女兒，這條 6 個任務把兩個人串在一起。10 等先幫義安打 50 隻木妖、幫布魯斯收菇菇寶貝傘跟蘑菇芽孢，再把玩具刀、信件在兩人之間送來送去，原來義安就是布魯斯失去記憶的女兒。52 等之後義安會再請你去沼澤打鱷魚，這兩個合計 45,000 經驗，還有武器攻擊卷軸 10% 和披風力量、智力、敏捷、幸運卷軸 60%。

> **一分鐘看懂**
> - **10 等（1～4）：** 木妖 50 隻、菇菇寶貝傘 40＋蘑菇芽孢 10，這兩個都做完才能接「尋找女兒」；四個合計 800 經驗＋500 楓幣。
> - **52 等（5）：** 青蛇 40、鱷魚 250、蛇皮 20，拿 20,000 經驗＋你職業能用的武器攻擊卷軸 10%。
> - **52 等（6）：** 黑鱷魚 120、黑鱷魚皮 50，拿 25,000 經驗＋披風力量、智力、敏捷、幸運卷軸 60% 各一張。

## 每個任務怎麼解

<!-- gen:steps -->

每個任務去哪接、要做什麼、拿什麼，都照遊戲資料。 {{src:game}}

### 1. [木妖好可怕](/db/quests/2082)（10 等）

- **去哪接**：到[勇士之村](/db/maps/102000000)找[義安](/db/npcs/1022007)接任務（Lv.10 以上可接）。
- 怎麼去：從墮落城市出發，墮落城市北入口 → 墮落城市北方工地 → 勇士之村西部 → 西部岩山Ⅰ → 勇士村西入口 → 勇士之村。
- **要打的怪**：[木妖](/db/monsters/130100) 50 隻：最多的圖是[魔法森林南郊](/db/maps/100050000)，其次[法師修練場](/db/maps/910220000)、[東方岩石山Ⅰ](/db/maps/101030400)。
- **回去交任務**：做完回去找[義安](/db/npcs/1022007)交任務。
- **獎勵**：經驗 300。

### 2. [研究菇菇怪物](/db/quests/2088)（10 等）

- **去哪接**：到[弓箭手村](/db/maps/100000000)找[布魯斯](/db/npcs/1012111)接任務（Lv.10 以上可接）。
- 怎麼去：從奇幻村出發，黑森林通道 → 弓箭手村迷宮入口 → 迷宮通道 → 弓箭手村。
- **要交的道具**：[菇菇寶貝傘](/db/items/4000001) 40 個：[菇菇寶貝](/db/monsters/1210102)（[可疑的山丘](/db/maps/100010100)）會掉。
- [蘑菇芽孢](/db/items/4000011) 10 個：[菇菇仔](/db/monsters/120100)（[菇菇山](/db/maps/104030001)）會掉。
- **回去交任務**：做完回去找[布魯斯](/db/npcs/1012111)交任務。
- **獎勵**：經驗 300。
- 道具：[紅色藥水](/db/items/2000000) ×25。

### 3. [尋找女兒 1](/db/quests/2092)（10 等）

- **去哪接**：到[弓箭手村](/db/maps/100000000)找[布魯斯](/db/npcs/1012111)接任務（Lv.10 以上可接）。
- 怎麼去：從奇幻村出發，黑森林通道 → 弓箭手村迷宮入口 → 迷宮通道 → 弓箭手村。
- **要交的道具**：[玩具刀](/db/items/4031174) 1 個。
- **回去交給誰**：到[勇士之村](/db/maps/102000000)找[義安](/db/npcs/1022007)交任務（不是接任務的布魯斯）。
- 怎麼去：從墮落城市出發，墮落城市北入口 → 墮落城市北方工地 → 勇士之村西部 → 西部岩山Ⅰ → 勇士村西入口 → 勇士之村。

### 4. [尋找女兒 2](/db/quests/2093)（不限等級）

- **去哪接**：到[勇士之村](/db/maps/102000000)找[義安](/db/npcs/1022007)接任務。
- 怎麼去：從墮落城市出發，墮落城市北入口 → 墮落城市北方工地 → 勇士之村西部 → 西部岩山Ⅰ → 勇士村西入口 → 勇士之村。
- **要交的道具**：[義安的信](/db/items/4031173) 1 個。
- **回去交給誰**：到[弓箭手村](/db/maps/100000000)找[布魯斯](/db/npcs/1012111)交任務（不是接任務的義安）。
- 怎麼去：從奇幻村出發，黑森林通道 → 弓箭手村迷宮入口 → 迷宮通道 → 弓箭手村。
- **獎勵**：經驗 200 · 楓幣 500。
