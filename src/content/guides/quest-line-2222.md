# 楓之谷經典版惡靈森林系列任務攻略：7 個任務怎麼接、去哪打、拿什麼

楓之谷經典版魔法森林的**妖精 艾溫**在森林裡被一隻巨大的猴怪攻擊，她說這要怪魔法森林圖書館的**漢斯**年輕時留下的黑魔法。順著線索找到魔法森林北部的貓**潘喜**，再進詛咒之林見到幽靈**利普**，才知道整件事的來龍去脈。這條 50 等可以接，整條 7 個任務、合計 112,800 經驗，全部在最後打 1 隻殭屍猴王那一步。

> **一分鐘看懂**
> - **幾等：** 50 等可接，在魔法森林、魔法森林圖書館、魔法森林北部、詛咒之林之間跑。
> - **要打的：** 巫婆的詛咒針 10 個（巫婆森林Ⅱ）、殭屍猴王 1 隻（巫婆森林Ⅰ最多）。
> - **詛咒之林：** 潘喜說入口在巫婆森林Ⅰ裡，任務說明寫利普在下午 5 點到隔天早上 7 點之間才出現。
> - **獎勵：** 「消滅殭屍猴王」112,800 經驗，最後利普再給人氣 8。

## 每個任務怎麼解

<!-- gen:steps -->

每個任務去哪接、要做什麼、拿什麼，都照遊戲資料。 {{src:game}}

### 1. [惡靈森林](/db/quests/2222)（50 等）

- **去哪接**：到[魔法森林](/db/maps/101000000)找[妖精 艾溫](/db/npcs/1032100)接任務（Lv.50 以上可接）。 [帶我去](/go?to=101000000)
- **回去交給誰**：到[魔法森林圖書館](/db/maps/101000003)找[漢斯](/db/npcs/1032001)交任務（不是接任務的妖精 艾溫）。
- 怎麼去：從魔法森林出發，魔法森林圖書館。

### 2. [他呼喚的名稱](/db/quests/2223)（不限等級）

- **去哪接**：到[魔法森林北部](/db/maps/101020000)找[潘喜](/db/npcs/1040002)接任務。
- 怎麼去：從魔法森林出發，魔法森林北郊 → 大木林Ⅰ → 魔法森林北部。
- **要交的道具**：[詛咒針](/db/items/4031925) 10 個：[巫婆](/db/monsters/5300100)（[巫婆森林Ⅱ](/db/maps/100040106)）會掉。
- **回去交任務**：做完回去找[潘喜](/db/npcs/1040002)交任務。

### 3. [怨恨、埋怨、冤魂](/db/quests/2224)（不限等級）

- **去哪接**：到[魔法森林北部](/db/maps/101020000)找[潘喜](/db/npcs/1040002)接任務。
- 怎麼去：從魔法森林出發，魔法森林北郊 → 大木林Ⅰ → 魔法森林北部。
- **回去交給誰**：到[詛咒之林](/db/maps/910100000)找[利普](/db/npcs/1032107)交任務（不是接任務的潘喜）。
- 怎麼去：從魔法森林出發，魔法森林南郊 → 智慧森林 → 猴子森林I → 猴子森林Ⅱ → 巫婆森林Ⅰ → 詛咒之林。

### 4. [原因和結果](/db/quests/2225)（不限等級）

- **去哪接**：到[詛咒之林](/db/maps/910100000)找[利普](/db/npcs/1032107)接任務。
- 怎麼去：從魔法森林出發，魔法森林南郊 → 智慧森林 → 猴子森林I → 猴子森林Ⅱ → 巫婆森林Ⅰ → 詛咒之林。
- **回去交給誰**：到[魔法森林](/db/maps/101000000)找[妖精 艾溫](/db/npcs/1032100)交任務（不是接任務的利普）。 [帶我去](/go?to=101000000)

### 5. [艾溫的道歉](/db/quests/2226)（不限等級）

- **去哪接**：到[魔法森林](/db/maps/101000000)找[妖精 艾溫](/db/npcs/1032100)接任務。 [帶我去](/go?to=101000000)
- **要交的道具**：[妖精的頭髮](/db/items/4031924) 1 個。
- **回去交給誰**：到[詛咒之林](/db/maps/910100000)找[利普](/db/npcs/1032107)交任務（不是接任務的妖精 艾溫）。
- 怎麼去：從魔法森林出發，魔法森林南郊 → 智慧森林 → 猴子森林I → 猴子森林Ⅱ → 巫婆森林Ⅰ → 詛咒之林。

### 6. [消滅殭屍猴王](/db/quests/2227)（不限等級）

- **去哪接**：到[魔法森林圖書館](/db/maps/101000003)找[漢斯](/db/npcs/1032001)接任務。
- 怎麼去：從魔法森林出發，魔法森林圖書館。
- **要打的怪**：[殭屍猴王](/db/monsters/5220002) 1 隻：最多的圖是[巫婆森林Ⅰ](/db/maps/100040105)，其次[巫婆森林Ⅱ](/db/maps/100040106)。
- **回去交任務**：做完回去找[漢斯](/db/npcs/1032001)交任務。
- **獎勵**：經驗 112,800。

### 7. [利普的道謝](/db/quests/2228)（不限等級）

- **去哪接**：到[詛咒之林](/db/maps/910100001)找[利普](/db/npcs/1032108)接任務。
- 怎麼去：從魔法森林出發，魔法森林南郊 → 智慧森林 → 猴子森林I → 猴子森林Ⅱ → 巫婆森林Ⅰ → 詛咒之林。
- **獎勵**：人氣 +8。
