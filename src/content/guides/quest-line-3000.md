# 楓之谷經典版查里中士的下落系列任務攻略：7 個任務怎麼接、去哪打、拿什麼

楓之谷經典版冰原雪域的**珀斯上尉**要你去找三個下落不明的軍人：天空之城的查里中士、寒冰平原的巴伯下士、雲彩公園Ⅵ的伊吉上等兵。40 等可接，一個一個找到人、幫他們帶一樣東西，再把古代文書碎片帶回珀斯上尉。7 個任務合計 19,600 經驗，最後一個給 7,000 經驗，隨機拿一張鞋子跳躍卷軸或鞋子速度卷軸（60% 或 10%）。

> **一分鐘看懂**
> - **幾等：** 40 等可接，在冰原雪域、天空之城、寒冰平原、雲彩公園Ⅵ之間來回。
> - **要交的：** 紫礦石 2 個（查里中士）、朱礦石 2 個（巴伯下士）、藍寶石 2 個（伊吉上等兵）。紫礦石、朱礦石站上查不到哪隻怪掉，要自己先準備；藍寶石有維多利亞島的任務會給。
> - **不用打怪：** 整條沒有要打的怪，都是跑腿跟交東西。
> - **獎勵：** 最後一個隨機給鞋子跳躍卷軸或鞋子速度卷軸（60%／10%）。

## 每個任務怎麼解

<!-- gen:steps -->

每個任務去哪接、要做什麼、拿什麼，都照遊戲資料。 {{src:game}}

### 1. [查里中士的下落](/db/quests/3000)（40 等）

- **去哪接**：到[冰原雪域](/db/maps/211000000)找[珀斯上尉](/db/npcs/2020003)接任務（Lv.40 以上可接）。 [帶我去](/go?to=211000000)
- **回去交給誰**：到[天空之城](/db/maps/200000000)找[查里中士](/db/npcs/2010000)交任務（不是接任務的珀斯上尉）。 [帶我去](/go?to=200000000)
- **獎勵**：經驗 1,200。

### 2. [查里中士的請託](/db/quests/3039)（40 等）

- **去哪接**：到[天空之城](/db/maps/200000000)找[查里中士](/db/npcs/2010000)接任務（Lv.40 以上可接）。 [帶我去](/go?to=200000000)
- **要交的道具**：[紫礦石](/db/items/4011005) 2 個。
- **回去交任務**：做完回去找[查里中士](/db/npcs/2010000)交任務。
- **獎勵**：經驗 3,000。

### 3. [巴伯下士的下落](/db/quests/3001)（40 等）

- **去哪接**：到[天空之城](/db/maps/200000000)找[查里中士](/db/npcs/2010000)接任務（Lv.40 以上可接）。 [帶我去](/go?to=200000000)
- **回去交給誰**：到[寒冰平原](/db/maps/211050000)找[巴伯下士](/db/npcs/2030001)交任務（不是接任務的查里中士）。
- 怎麼去：從冰原雪域出發，冰面Ⅰ → 冰面Ⅱ → 結冰的平原Ⅰ → 結冰的平原Ⅱ → 寒冰平原。
- **獎勵**：經驗 1,200。

### 4. [巴伯下士的請託](/db/quests/3040)（40 等）

- **去哪接**：到[寒冰平原](/db/maps/211050000)找[巴伯下士](/db/npcs/2030001)接任務（Lv.40 以上可接）。
- 怎麼去：從冰原雪域出發，冰面Ⅰ → 冰面Ⅱ → 結冰的平原Ⅰ → 結冰的平原Ⅱ → 寒冰平原。

- **回去交任務**：做完回去找[巴伯下士](/db/npcs/2030001)交任務。

### 5. [伊吉上等兵的下落](/db/quests/3002)（40 等）

- **去哪接**：到[寒冰平原](/db/maps/211050000)找[巴伯下士](/db/npcs/2030001)接任務（Lv.40 以上可接）。
- 怎麼去：從冰原雪域出發，冰面Ⅰ → 冰面Ⅱ → 結冰的平原Ⅰ → 結冰的平原Ⅱ → 寒冰平原。

- 怎麼去：從天空之城出發，雲彩公園Ⅰ → 雲彩公園Ⅱ → 散步路Ⅰ → …（共 8 張） → 雲彩公園Ⅴ → 雲彩公園Ⅵ。
- **獎勵**：經驗 1,200。

### 6. [伊吉上等兵的請託](/db/quests/3041)（40 等）

- **去哪接**：到[雲彩公園Ⅵ](/db/maps/200080000)找[伊吉上等兵](/db/npcs/2030002)接任務（Lv.40 以上可接）。

- **獎勵**：經驗 3,000。

### 7. [返回珀斯上尉之處](/db/quests/3003)（40 等）

- **回去交給誰**：到[冰原雪域](/db/maps/211000000)找[珀斯上尉](/db/npcs/2020003)交任務（不是接任務的伊吉上等兵）。 [帶我去](/go?to=211000000)
