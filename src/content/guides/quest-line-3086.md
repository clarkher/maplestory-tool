# 楓之谷經典版史菲魯納的預言系列任務攻略：5 個任務怎麼接、去哪打、拿什麼

楓之谷經典版天空之城**老婆之屋**的史菲魯納跟她的助手，要你幫忙「減輕天空之城的重量」。30 等可接，5 個任務合計 10,550 經驗，經驗不多，重點是兩個隨機獎勵：幼紅、幼黃、幼藍獨角獅各打 80 隻，給 5 個礦石母礦（7 種隨機一種）；收 25 個魔雲碎片，給 5 個寶石母礦（9 種隨機一種，有機會是鑽石母礦、黑水晶母礦）。最後兩個是幫助手跟管家艾瑪拿回噴霧器，給白色藥水 30 瓶。

> **一分鐘看懂**
> - **幾等：** 30 等可接，任務都在老婆之屋，管家艾瑪在天空之城公園。
> - **打怪：** 幼紅、幼黃、幼藍獨角獅各 80 隻，分別在紅光、黃光、藍光庭園Ⅰ最多。
> - **魔雲碎片 25 個：** 星光精靈、月光精靈、日光精靈都會掉。
> - **獎勵：** 礦石母礦 ×5、寶石母礦 ×5 各隨機一種，噴霧器那關給白色藥水 ×30。

## 每個任務怎麼解

<!-- gen:steps -->

每個任務去哪接、要做什麼、拿什麼，都照遊戲資料。 {{src:game}}

### 1. [史菲魯納的預言](/db/quests/3086)（30 等）

- **去哪接**：到[老婆之屋](/db/maps/200050001)找[史菲魯納](/db/npcs/2032001)接任務（Lv.30 以上可接）。
- 怎麼去：從天空之城出發，雲彩公園Ⅰ → 雲彩公園Ⅱ → 散步路Ⅰ → 雲彩公園Ⅲ → 雲彩公園Ⅳ → 老婆之屋。
- **獎勵**：經驗 50。

### 2. [減輕天空之城的重量](/db/quests/3087)（30 等）

- **去哪接**：到[老婆之屋](/db/maps/200050001)找[助手](/db/npcs/2032000)接任務（Lv.30 以上可接）。
- 怎麼去：從天空之城出發，雲彩公園Ⅰ → 雲彩公園Ⅱ → 散步路Ⅰ → 雲彩公園Ⅲ → 雲彩公園Ⅳ → 老婆之屋。
- **要打的怪**：[幼紅獨角獅](/db/monsters/3210200) 80 隻：最多的圖是[紅光庭園Ⅰ](/db/maps/200010110)，其次[前往三色庭園的路](/db/maps/200010100)。
- [幼黃獨角獅](/db/monsters/3210201) 80 隻：最多的圖是[黃光庭園Ⅰ](/db/maps/200010120)，其次[前往三色庭園的路](/db/maps/200010100)。
- [幼藍獨角獅](/db/monsters/3210202) 80 隻：最多的圖是[藍光庭園Ⅰ](/db/maps/200010130)，其次[前往三色庭園的路](/db/maps/200010100)。
- **回去交任務**：做完回去找[助手](/db/npcs/2032000)交任務。
- **獎勵**：經驗 4,500。
- 從這幾樣隨機給一樣：[鋼鐵母礦](/db/items/4010001) ×5、[青銅母礦](/db/items/4010000) ×5、[鋰礦石母礦](/db/items/4010002) ×5、[紫礦石母礦](/db/items/4010005) ×5、[朱礦石母礦](/db/items/4010003) ×5、[銀的母礦](/db/items/4010004) ×5、[黃金母礦](/db/items/4010006) ×5。

### 3. [收集精靈的雲塊](/db/quests/3088)（30 等）

- **去哪接**：到[老婆之屋](/db/maps/200050001)找[助手](/db/npcs/2032000)接任務（Lv.30 以上可接）。
- 怎麼去：從天空之城出發，雲彩公園Ⅰ → 雲彩公園Ⅱ → 散步路Ⅰ → 雲彩公園Ⅲ → 雲彩公園Ⅳ → 老婆之屋。
- **要交的道具**：[魔雲碎片](/db/items/4031309) 25 個：[星光精靈](/db/monsters/3230200)（[雲彩公園Ⅰ](/db/maps/200010000)）、[月光精靈](/db/monsters/4230106)（[雲彩公園Ⅳ](/db/maps/200050000)）、[日光精靈](/db/monsters/5120000)（[雲彩公園Ⅵ](/db/maps/200080000)）會掉。
- **回去交任務**：做完回去找[助手](/db/npcs/2032000)交任務。
- **獎勵**：經驗 5,000。
- 從這幾樣隨機給一樣：[石榴石母礦](/db/items/4020000) ×5、[紫水晶母礦](/db/items/4020001) ×5、[海藍石母礦](/db/items/4020002) ×5、[祖母綠母礦](/db/items/4020003) ×5、[蛋白石母礦](/db/items/4020004) ×5、[藍寶石母礦](/db/items/4020005) ×5、[黃晶母礦](/db/items/4020006) ×5、[鑽石母礦](/db/items/4020007) ×5、[黑水晶母礦](/db/items/4020008) ×5。

### 4. [艾瑪借走的噴霧器1](/db/quests/3089)（30 等）

- **去哪接**：到[老婆之屋](/db/maps/200050001)找[助手](/db/npcs/2032000)接任務（Lv.30 以上可接）。
- 怎麼去：從天空之城出發，雲彩公園Ⅰ → 雲彩公園Ⅱ → 散步路Ⅰ → 雲彩公園Ⅲ → 雲彩公園Ⅳ → 老婆之屋。
- **回去交給誰**：到[天空之城公園](/db/maps/200000200)找[管家 艾瑪](/db/npcs/2012010)交任務（不是接任務的助手）。
- 怎麼去：從天空之城出發，天空之城公園。
- **獎勵**：經驗 500。

### 5. [艾瑪借走的噴霧器2](/db/quests/3090)（30 等）

- **去哪接**：到[天空之城公園](/db/maps/200000200)找[管家 艾瑪](/db/npcs/2012010)接任務（Lv.30 以上可接）。
- 怎麼去：從天空之城出發，天空之城公園。
- **要交的道具**：[雲朵噴霧器](/db/items/4031308) 1 個。
- **回去交給誰**：到[老婆之屋](/db/maps/200050001)找[助手](/db/npcs/2032000)交任務（不是接任務的管家 艾瑪）。
- 怎麼去：從天空之城出發，雲彩公園Ⅰ → 雲彩公園Ⅱ → 散步路Ⅰ → 雲彩公園Ⅲ → 雲彩公園Ⅳ → 老婆之屋。
- **獎勵**：經驗 500。
- 道具：[白色藥水](/db/items/2000002) ×30。
