# 楓之谷經典版阿勒斯與長老斯坦系列任務攻略：3 個任務怎麼接、去哪打、拿什麼

楓之谷經典版墮落城市的少年**阿勒斯**跟嚴厲的父親鬧彆扭離家出走，錢花光了又不敢回家，拜託你去弓箭手村說服他父親**長老斯坦**。搜「說服長老斯坦」找的就是這條的第二步。整條 3 個任務、20 等就能接，合計 6,600 經驗，最後把母親的金錶送回去，阿勒斯會隨機給一副耳環。

> **一分鐘看懂**
> - **幾等：** 20 等可接，在墮落城市跟弓箭手村之間來回。
> - **要打的只有一步：** 長老斯坦要火獨眼獸之尾巴 30 個（火獨眼獸洞穴）、蝴蝶結 60 個（緞帶肥肥）。
> - **對話要選對：** 這條有一段要選對話選項，站上升級路線整理的玩家選法是 2→3→3→1→3。
> - **獎勵：** 金錶送回墮落城市拿 5,000 經驗，隨機一副耳環：金耳環、紅十字耳環、來電耳環、祖母綠耳環。

## 每個任務怎麼解

<!-- gen:steps -->

每個任務去哪接、要做什麼、拿什麼，都照遊戲資料。 {{src:game}}

### 1. [阿勒斯的請託](/db/quests/2014)（20 等）

- **去哪接**：到[墮落城市](/db/maps/103000000)找[阿勒斯](/db/npcs/1052000)接任務（Lv.20 以上可接）。
- 怎麼去：從勇士之村出發，勇士村西入口 → 西部岩山Ⅰ → 勇士之村西部 → 墮落城市北方工地 → 墮落城市北入口 → 墮落城市。
- **回去交給誰**：到[弓箭手村](/db/maps/100000000)找[長老斯坦](/db/npcs/1012003)交任務（不是接任務的阿勒斯）。
- 怎麼去：從奇幻村出發，黑森林通道 → 弓箭手村迷宮入口 → 迷宮通道 → 弓箭手村。

### 2. [說服長老斯坦](/db/quests/2015)（20 等）

- **去哪接**：到[弓箭手村](/db/maps/100000000)找[長老斯坦](/db/npcs/1012003)接任務（Lv.20 以上可接）。
- 怎麼去：從奇幻村出發，黑森林通道 → 弓箭手村迷宮入口 → 迷宮通道 → 弓箭手村。
- **要交的道具**：[火獨眼獸之尾巴](/db/items/4000007) 30 個：[火獨眼獸](/db/monsters/2230100)（[火獨眼獸洞穴II](/db/maps/105070200)）會掉。
- [蝴蝶結](/db/items/4000002) 60 個：[緞帶肥肥](/db/monsters/1210101)（[弓箭手村西部小山](/db/maps/104030000)）會掉。
- **回去交任務**：做完回去找[長老斯坦](/db/npcs/1012003)交任務。
- **獎勵**：經驗 1,600。

### 3. [母親的金錶](/db/quests/2016)（20 等）

- **去哪接**：到[弓箭手村](/db/maps/100000000)找[長老斯坦](/db/npcs/1012003)接任務（Lv.20 以上可接）。
- 怎麼去：從奇幻村出發，黑森林通道 → 弓箭手村迷宮入口 → 迷宮通道 → 弓箭手村。
- **要交的道具**：[舊金錶](/db/items/4031007) 1 個。
- **回去交給誰**：到[墮落城市](/db/maps/103000000)找[阿勒斯](/db/npcs/1052000)交任務（不是接任務的長老斯坦）。
- 怎麼去：從勇士之村出發，勇士村西入口 → 西部岩山Ⅰ → 勇士之村西部 → 墮落城市北方工地 → 墮落城市北入口 → 墮落城市。
- **獎勵**：經驗 5,000。
- 從這幾樣隨機給一樣：[金耳環](/db/items/1032004)、[紅十字耳環](/db/items/1032005)、[來電耳環](/db/items/1032006)、[祖母綠耳環](/db/items/1032007)。
