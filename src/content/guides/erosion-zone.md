# 楓之谷經典版侵蝕地帶調查：1/7 開放、六個地區入場等級

**侵蝕地帶調查**是楓之谷經典版台服原創的成長玩法，**1/7（四）開放**。組隊打被侵蝕的怪拿經驗。這篇整理發佈會公布的地區跟等級，實際玩法開放後補。

> **一分鐘看懂**
> - **開放**：1/7（四）
> - **組隊**：最多 3 人
> - **打什麼**：被侵蝕的怪物
> - **獎勵**：經驗；每日任務跟硬幣商店也會增加
> - **六個地區**，25 等就能進（墮落城市）

---

## 六個地區、入場等級

| 地區 | 可入場等級 |
|---|---|
| [墮落城市](/db/maps/103000000) | 25～40 |
| [勇士之村](/db/maps/102000000) | 35～55 |
| [天空之城](/db/maps/200000000) | 50～70 |
| [奇幻村](/db/maps/105040300) | 65～85 |
| [冰原雪域](/db/maps/211000000) | 80～105 |
| 廢棄礦坑 | 100～150 |

- 每段都跟下一段重疊 5～15 等，**卡在中間的可以挑人少的那區**。
- 廢棄礦坑寫到 150，比現在的 120 等上限還高；發佈會同時說等級上限會擴充，數字還沒公布。
- 來源：發佈會投影片（[現場照片](https://forum.gamer.com.tw/C.php?bsn=85994&snA=2447)、[直播](https://www.youtube.com/live/k_9xh-mwxgw)）。

## 怎麼玩（已公布的部分）

| 項目 | 發佈會講的 |
|---|---|
| 組隊 | 最多 3 人 |
| 怪物 | 被侵蝕的怪物（投影片上是現有的怪，身上冒紅黑色煙霧） |
| 獎勵 | 經驗 |
| 其他 | 每日任務、硬幣商店增加 |

- 投影片畫的是冰原雪域雪地上的一個紅色裂縫，實際怎麼進場等開放後補。
- 「每日任務」代表會有每天固定要解的東西，硬幣商店換什麼**還沒公布**。

---

## 開放前先做什麼

1. **把等級拉到你想去的那區**：照職業看[分等級攻略](/guides)，每篇都有站上算的幾下打死、10 分鐘經驗。
2. **先找 2 個隊友**：最多 3 人，固定隊比路人好約。
3. 1/7 同一天還有冒險家的戒指第二次覺醒，現在的戒指任務線先解完：[冒險家的戒指](/guides/adventurer-ring)。

## 等開放後補

- 裂縫在每個地區的哪張圖、一天能進幾次
- 每個地區的經驗多少、跟一般練功圖比起來划不划算
- 每日任務內容、硬幣商店換什麼
- 被侵蝕的怪跟原本的怪差在哪
