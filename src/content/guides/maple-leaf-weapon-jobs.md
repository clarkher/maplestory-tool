# 楓之谷經典版楓葉武器哪些職業值得換？每把用到幾等一次看

楓之谷經典版的楓葉商會 11/19 開跑，一把 43 級楓葉武器 200 枚。**換之前先看你的職業划不划算**：下面用站上的[傷害計算機](/plan/damage)算，楓葉武器衝完，跟同等級拿得到最好的武器打木樁比傷害。活動規則跟衝卷懶人包在[楓葉商會攻略](/guides/maple-leaf-shop)。

> **一分鐘看懂**
> - **最值得：** 刺客的楓葉拳套、槍騎兵的楓葉之槍，衝完一路強到 70 等。
> - **很值得：** 獵人的楓葉之弓、打手的楓葉暴風指虎，用到 69 等。
> - **值得：** 弩弓手、俠盜、槍手，用到 59 等。
> - **差不多：** 法師三種，楓葉法杖只強 6%，有幣再換。
> - **不建議：** 劍士的楓葉戰斧、楓葉戰鎚、楓葉之劍，太慢或太弱。

## 每個職業換哪把、用到幾等

| 職業 | 換這把 | 用到 |
|---|---|---|
| 刺客 | 楓葉拳套 | 70 以上 |
| 槍騎兵 | 楓葉之槍 | 70 以上 |
| 獵人 | 楓葉之弓 | 69 等 |
| 打手 | 楓葉暴風指虎 | 69 等 |
| 弩弓手 | 楓葉之弩 | 59 等 |
| 俠盜 | 楓葉短刀 | 59 等 |
| 槍手 | 楓葉暴風火槍 | 59 等 |
| 法師三種 | 楓葉法杖 | 57 等 |
| 狂戰士 | 楓葉戰劍 | 49 等 |
| 見習騎士 | 楓葉戰劍 | 49 等 |

- **用到幾等**＝衝完的楓葉武器，到這一級都不輸同等級拿得到最好的武器；再上去就被追過。
- 「70 以上」是比到 70 等都還贏，三轉之後技能跟武器都換一輪，這篇不算。
- 還沒 43 等的人：35 級那把（100 枚）也能先用，見下面每個職業的表。

## 怎麼算的

- **角色：** 傷害計算機在那個等級的預設角色（主流點法、主流技能），打木樁，[自己的數字可以去計算機改](/plan/damage)。
- **楓葉武器：** 武器攻擊（法師是魔攻）多 12，就是照[懶人包](/guides/maple-leaf-shop#懶人包-照天數這樣走)衝完的平均 +11.6。
- **比的對象：** 同一級拿得到（商店、打怪掉、任務、製作）最好的那把，**沒衝卷**。別把也衝卷的話，楓葉武器的優勢會變小。
- **每秒傷害：** 一下的平均傷害 × 一秒出手幾次（照武器攻速、二轉加速技能）。
- 比 35～70 等每一級，「用到」是最後一級還不輸（差不到 0.5% 算打平）。
