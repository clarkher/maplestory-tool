# 職業路線首頁 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 首頁改成「選職業＋等級 → 今天跑哪幾趟＋升級路線」，17 職都有點法、練功點、必解任務、先存材料。

**Architecture:** 玩家攻略研究檔進版控（`data/guides/`），由 `pipeline/build-guides.mjs` 驗證 id 後壓成每職一檔的 `public/data/guides/*.json`。
純函式放 `src/lib/`（職業、技能點、路線規劃），用 vitest 測；畫面拆成 `src/components/route/` 幾個元件，首頁組起來。

**Tech Stack:** Next.js 16 App Router（全站靜態）、React 19、Tailwind 4、TypeScript、vitest（新增）。

Spec：`docs/superpowers/specs/2026-10-03-job-route-design.md`

---

## File Structure

| 檔案 | 責任 |
|---|---|
| `data/guides/{warrior-pirate,magician,archer-thief,quests-exp}.json` | 研究原檔（含出處），人與 routine 維護的來源 |
| `pipeline/build-guides.mjs` | 驗證研究檔的技能／地圖／怪物 id，輸出 `public/data/guides/{jobId}.json` 與 `common.json` |
| `src/lib/jobs.ts` | 17 職清單、一轉／二轉判斷、轉職等級、轉職教官、舊代碼正規化 |
| `src/lib/skill-plan.ts` | 某職某等級的可用技能點、點法走到第幾步 |
| `src/lib/route-planner.ts` | 等級段、每段練功／必解／先存、今天的幾趟、長線任務 |
| `src/lib/types.ts` | 加 guides 相關型別 |
| `src/lib/data.ts` | 加 `loadGuide(job)`、`loadGuideCommon()` |
| `src/components/route/*.tsx` | 角色列、技能條、一趟卡、長線、升級路線 |
| `src/app/page.tsx` | 首頁組裝 |
| `src/app/db/page.tsx` | 查資料索引頁 |
| `src/components/SiteHeader.tsx` | 導覽列改三項 |
| `src/components/ProfileForm.tsx` | 職業選單改 17 職 |
| `src/lib/__tests__/*.test.ts` | 單元測試 |

### Task 3：`jobs.ts`（TDD）
測試：
- `JOB_OPTIONS` 有 17 個，id 為 100,110,120,130,200,210,220,230,300,310,320,400,410,420,500,510,520。
- `baseJob(110)===100`、`baseJob(100)===100`、`isSecondJob(110)` 為 true、`isSecondJob(100)` 為 false。
- `advancementLevel(200)===8`、`advancementLevel(310)===10`。
- `normalizeJob(1110)===0`、`normalizeJob(431)===0`、`normalizeJob(220)===220`。

### Task 4：`skill-plan.ts`（TDD）
測試：
- `availableSp(100, 9)===0`、`availableSp(100, 10)===1`、`availableSp(100, 30)===61`、`availableSp(200, 30)===67`。
- `availableSp(110, 30)===1`、`availableSp(110, 35)===16`、`availableSp(110, 25)===46`（未滿 30 回一轉點數）。
- `stageJob(110, 25)===100`、`stageJob(110, 35)===110`。
- `buildProgress`：同一技能出現兩次時只算差額；點數剛好用完的那一步標 `now`，之後第一步標 `next`，再之後 `later`，之前 `done`；點數超過全部步驟時最後一步為 `done` 且回 `finished: true`。

### Task 5：`route-planner.ts`（TDD）
測試：
- `bandsFor(200)` 第二段從 8 開始；`bandsFor(110)` 有 8 段且最後一段 70–100；`bandOf(bands, 35)` 回 30–40。
- `questDoableAt`：要打的怪都在圖上、要交的道具都由圖上的怪掉才 true；有一項不在就 false；沒有任何需求的任務回 false。
- `levelFraction(24000, 35, toNext)` 約 0.14。
- `planTrips`：同一張圖同時是「最快」與「最多任務」時合併成一趟、兩個標籤；最多 3 趟。
- `prepMaterials`：同一道具多個任務要時數量加總，並列出掉落怪。
