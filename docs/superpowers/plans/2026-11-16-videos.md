# 官網影片區 實作計畫（v2.32）

規格：docs/superpowers/specs/2026-11-16-videos-design.md

1. `src/lib/videos.ts`：`VideoEpisode` 型別、`EPISODES`、`visibleEpisodes(now)`（公開時間 ≤ now、新到舊）。
   測試 `src/lib/__tests__/videos.test.ts`：篩選與排序、id 是 11 碼、每個 id 都有 `public/videos/<id>.webp`、工具連結是站內路徑。先寫測試看它紅。
2. `scripts/video-covers.mjs`：從 mp4 抽 1.5 秒那格轉 webp。產 6 集封面。
3. `src/components/VideoPlayer.tsx`（client）：封面＋播放鈕（inline SVG），點了換 nocookie iframe；`aspect-video`／`aspect-[9/16]` 固定框。
4. `/videos` 頁：server 先照建置時間篩，client 掛上後照現在時間重篩；短影音一排橫捲、正片格狀；VideoObject JSON-LD。
5. `/guides` 頁首下面一排最新 4 支短影音＋「看全部影片」；頁尾加「影片」；site-pages 加 /videos；隱私權政策加一句。
6. 驗收：npm test、next build、無頭 Chrome 截 /videos 手機與電腦、點播放確認 iframe 出現且版面不跳。
