# 第二批攻略文：系列任務、地區任務懶人包、職業配點（11/13 拍板 A）

## 為什麼做

Search Console 28 天（到 11/10）前 150 個搜尋字裡，扣掉萬聖節，最大的三塊沒有文章接：

- **系列任務名**：「利普的道謝」「波達的請求」「珍的第一個挑戰」「巴伯下士」「說服長老斯坦」——現在只落在任務單獨頁，一頁只講一個任務，看不到前後。
- **地區任務**：「惡靈森林」「詛咒之林」「酋長蓋房子」「離家少年阿勒斯」——想知道一個地方有哪些任務、照什麼順序解。
- **職業配點**：「楓之谷經典版龍騎士配點」「遊俠技能配點」「獵人技能點法」「暗殺者配點」——37 篇職業攻略照等級切，沒有一篇標題叫「配點」。

成功的樣子：上線 2 週後 Search Console 這三類搜尋字有點擊進到新文章（基線：11/13 那次分析，見記憶 maplebook-data-analysis-1111）。

## 範圍

**要做（約 40 篇）**

1. **系列任務**：一條系列一篇。收錄條件：一般任務（不含萬聖節、活動、組隊、稱號、轉職）用前置任務串成一條、5 個以上；另外不到 5 個但 Search Console 有人搜的也收：珍的挑戰（4）、阿勒斯／說服長老斯坦（3）、酋長蓋房子（2）。（實作者的決定：審稿發現這幾個搜尋字原本對不到文章）
   起始清單（11/13 從 public/data/quests.json 算的，實作時重算）：古代之書（32）、神秘書／詛咒娃娃（14）、特奧／舊戰劍（13）、波達（11）、麥加的修煉（9）、樹妖王（9）、赫麗娜（9）、吉姆發現的陰謀（9）、艾斯達的甜蜜果漿（9）、好無聊（8）、瑞恩的測驗（7）、危險的迷宮（7）、惡靈森林（7）、查里中士（7）、瑪帕的請託（6）、化石（6）、尋找女兒／鱷魚（6）、雪毛怪人（6）、巨居蟹（5）、貝恩／黑影（5）、史菲魯納（5）、珍的挑戰（4）。
   不收：冒險家的戒指（已有文章）、推薦職業、X之路（新手轉職，/guide 已講）、萬聖節。
2. **地區任務懶人包**：每區一篇，照 quests.json 的 cat：楓之島、維多利亞島、冰原雪域，共 3 篇（「其他任務」只有 5 個開發測試任務 9250～9254，不做；天空之城在冰原雪域那類裡）。列這區所有一般任務，照等級排，系列任務連到第 1 類文章。
3. **職業配點**：二轉職業線一篇，共 12 篇（狂戰士、見習騎士、槍騎兵、火毒、冰雷、僧侶、獵人、弩弓手、刺客、俠盜、打手、槍手）。一轉→二轉→三轉每段技能怎麼點、能力值（AP）怎麼配。

**不做**：萬聖節與其他已結束活動、組隊任務（/guide 已有）、勳章（已有文章）、四轉（客戶端沒開）、沒開放地區的任務。

**做壞的樣子（就算技術上能動也不算成功）**：編任務流程或技能用法、寫遊戲裡沒有的攻略建議、文章裡有真實品牌名、表格跟查資料頁數字對不上、只有表格沒有一句人話。

## 做法（選 A：全部量產）

三個做法比過：
- **A 全部量產（使用者選）**：三類都出文章，表格程式產、文字人寫。篇數多、搜尋字最對得上。
- B 只做懶人包＋配點：篇數少但系列任務名搜不到。
- C 系列任務做成自動頁、不算文章：量大但進不了攻略專區、沒有攻略寫法。

### 共用

- 三類都放 `src/content/guides/<slug>.md`，沿用 v1.88 一般攻略文（自動進攻略專區、建置時擋標題沒寫楓之谷經典版、圖不存在）。
- **表格由程式產、文字由人寫**：新腳本 `scripts/guide-batch.mjs` 從 public/data 產表格，寫進 md 裡 `<!-- gen:<名稱> -->` 到 `<!-- /gen -->` 之間；標記外面是人寫的字，重跑只換標記裡面。資料更新後重跑就同步。
- 加測試：每篇 md 的產生區塊跟現在資料重算一致（不一致就紅，像 article:check 的作用），連到 /db 的連結都要查得到：現有 404 測試只查道具、任務、怪物，要補 NPC、地圖、技能。
- 標題、內文都有「楓之谷經典版」（既有規則）。
- 每篇在 `RELATED_RULES` 登記等級範圍（系列：該系列最低～最高等級；懶人包：該區；配點：10～120）。
- 每篇主圖用 `scripts/guide-card-heroes.mjs`，底稿＝真地圖＋真怪／NPC，AI 重繪、不准有字；約 38 張，製作期成本照使用者規則不省。
- 分類：系列、懶人包放「任務」；配點放「職業攻略」，標籤帶職業線、一轉／二轉／三轉。

### 1. 系列任務

- 網址：`/guides/quest-line-<第一個任務 id>`（不用拼音，避免猜錯中文名）。
- 標題：`楓之谷經典版<系列名>任務攻略：<N> 個任務怎麼接、去哪打、拿什麼`。系列名取第一個任務或使用者最常搜的那個名字。
- 內容：
  - 一分鐘看懂（幾等開始、總經驗、最值得拿的獎勵、大概要跑幾張圖）
  - 每個任務一節：誰給（NPC＋地圖、「帶我去」）、要做什麼（打哪隻怪幾隻、交什麼，怪連「哪裡最多」）、交給誰、經驗與獎勵。
  - 系列分叉（古代之書是一棵樹）：主線照前置順序寫，分支另開小節標「做完 X 後可以接」（實作者的決定）。
  - 「卡關常見原因」只寫資料查得到的（例如要先完成／不能接過，照 v1.60 前置狀態）。
- 來源標示照既有三色（遊戲資料／站上計算／參考舊版資料）。一般攻略文的 Markdown 現在畫不出三色，要擴充 `src/lib/guide-markdown.ts` 加一個來源標記寫法（實作者的決定）。

### 2. 地區任務懶人包

- 網址：`/guides/quests-<maple-island|victoria|el-nath>`。
- 標題：`楓之谷經典版<地區>任務總整理：<N> 個任務照等級排、哪些必解`。
- 排序（實作者的決定）：楓之島 52 個有 45 個沒寫等級，整篇照接的順序（前置任務）排；其他兩區照等級排，沒寫等級的放「不限等級」一段。
- 內容：照等級分段的大表（任務、幾等、誰給、經驗、獎勵、系列文章連結）；「必解」只標效益規則認定的（關鍵獎勵＋經驗，見記憶 maplebook-efficiency-rule）。

### 3. 職業配點

- 網址：`/guides/skill-build-<二轉 JOB_SLUGS>`，例如 `skill-build-spearman`。
- 標題：`楓之谷經典版<三轉名>配點：<二轉名>一轉到三轉技能怎麼點、能力值怎麼配`（搜尋會用三轉名，例如龍騎士、遊俠）。
- 內容：
  - 一分鐘看懂（主流點法一句話、AP 一句話）
  - 每轉一節：照等級排的點法表（第幾等點什麼到幾級），**由程式從 `public/data/guides/<職業>.json` 的 `builds` 產**，用 `mainBuild()` 挑的那套（跟首頁升級路線、計算機同一套）；有其他主流點法的列在下面「另一種點法」短表。37 篇職業攻略「技能怎麼點」那段文字跟這套不一致，**修文字、不動 json**（動 json 會連動首頁跟計算機）。（實作者的決定）
  - 「點得到第幾級」照 v0.78 規則先扣所需技能。技能名、所需技能用客戶端資料。
  - AP：照站上第二套配點（v0.76，全幸／裝備法），沒有的職業只寫主流一套。
  - 三轉段落：資料只到 1.15.x 客戶端，照實寫。十字軍、騎士、魔導士（火毒）、狙擊手、神偷、格鬥家這 6 條沒有三轉職業攻略、點法只有舊版，**照出、標「參考舊版資料」**（11/13 使用者拍板 A），之後有台服回報再更新。
- 寫手：用該職業線 31～50 那篇的寫手（同一個人講話一致）。

## 交付順序（每輪只進 dev，上正式機等使用者說）

1. 第一輪：`guide-batch.mjs`＋測試＋**樣本 4 篇**（波達系列、珍的挑戰、維多利亞島懶人包、槍騎兵／龍騎士配點），使用者看過再量產。
2. 第二輪：其餘系列任務＋懶人包。
3. 第三輪：其餘 11 篇配點。

每輪：feat 分支 → PR 進 dev → 三條 CI 綠 → 測試機實際打開截圖驗收（手機寬度也看）→ 自己挑 ≥10 點優化。
