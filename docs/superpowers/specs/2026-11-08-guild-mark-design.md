# 公會徽章模擬器設計

2026-11-08。使用者原話：「楓之谷 公會徽章 模擬器 有能做出來嗎」。

## 為什麼做

在遊戲裡做公會徽章，得先開公會、找會長、花楓幣才看得到成品，而且徽章在遊戲裡只有 17×17 這麼小。玩家想先在網頁上把底圖、圖案、顏色一個個換著看，挑到喜歡的再進遊戲照著做，或把組合丟給會長、會員一起選。

成功的樣子：玩家打開頁面，換幾種底圖跟圖案，看到放大的徽章跟遊戲裡實際大小的樣子，下載一張清楚的圖，或把連結丟進公會群組，大家點開看到同一個徽章。

## 圖從哪來（已經查過、實測過）

全部用**台服經典版客戶端**（1.15.3）本機檔案，路徑 `D:/屁哥/maplestory_classic/Maplestory_Classic_Data/StreamingAssets/aa/w/`：

- 大圖：`spritesheet_1023f33d7803aa6ebdb0af33806e9a14.bundle` 裡的 Texture2D `Assets/WzAssets/SpriteSheet/TW/UI/GuildMark_0.png`（1024×1024、RGBA32 不失真）。
- 每格的位置：同一包的 MonoBehaviour `GuildMark.wzspritesheet`（沒有 typetree，讀原始資料 `deref().get_raw_data()`）。從位移 `0xe4` 起 2,273 筆，每筆 4 個 int32：`x, y, 寬, 高`。**y 從圖的下緣往上算**，切圖要用 `top = 1024 - y - 高`。
- 有哪些底圖、圖案、顏色：`json_fc4e161bd2228c7902b6ad307a5548ba.bundle` 的 `Assets/WzAssets/Json/UI/GuildMark.wzjson`，用 repo 既有的 `scripts/client/wzjs.mjs`（`decodeBody`，body 從原始資料位移 44 開始）解得出樹：`BackGround/<8 碼>/<1～16>`、`Mark/<Animal|Plant|Pattern|Letter|Etc>/<8 碼>/<1～16>`，每格的 origin 都是 0,0。
- **哪一格是哪個底圖、哪個顏色**：客戶端用名字雜湊對照，雜湊算法沒解開（試過 md5、sha、xxHash3、SpookyHash 加各種路徑寫法都不中）。改用 maplestory.io 的舊版原圖當答案卷：`https://maplestory.io/api/wz/GMS/83/UI/GuildMark.img/<路徑>` 回 JSON，`value` 是那格 17×17 PNG（base64）。把舊版圖的透明邊裁掉，跟台服每格比像素——**11/08 實測 2,289 格全部找到差 0 的那格**，2,273 格台服圖全用到（16 格是兩個顏色共用同一張圖）。舊版圖裁掉的左上角位移，就是這格在 17×17 裡要放的位置。
  - 數量兩邊一樣：底圖 31（`00001000`～`00001030`）；圖案 動物 21（`00002000`～`00002020`）、植物 7（`00003000`～`00003006`）、花紋 22（`00004000`～`00004021`）、文字 36（`00005000`～`00005035`）、其他 27（`00009000`～`00009026`）。
  - 每個都有 16 色，**只有「其他」的 `00009026` 只有 1 色**。
  - 底圖跟圖案的 16 色是**兩套不同的顏色**（例：底圖第 1 色是紅、圖案第 1 色偏粉紅）。
  - 驗證時切錯過一次：一開始把那 4 個 int 當成「寬、高、x、y」從 `0xec` 讀，會切到旁邊那格的邊，腳本要留檢查（見下面）。

## 資料管線

- 新腳本 `scripts/client/guild-mark.py`（照 `scripts/client/quickslot-font.py` 的寫法：開頭寫用法、只讀客戶端、Python 3.11＋UnityPy＋numpy＋Pillow）。舊版答案卷第一次要抓 2,289 張，存在 `%TEMP%` 快取，不進 repo、不寫進遊戲資料夾。
- 產出（進 repo，建置不需要客戶端）：
  - `public/assets/guild-mark/marks-<內容雜湊>.png`：檔名帶內容雜湊（`/assets/` 快取一年不會變，客戶端加新圖案時換檔名才會更新；建置者決定），一張圖集，每列一個底圖或圖案、每欄一個顏色，每格 17×17 已經擺好位置（透明邊補好）。順序：31 個底圖，接著動物、植物、花紋、文字、其他。
  - `src/lib/guild-mark/marks.json`（或 .ts）：每個底圖／圖案的 id、分類、在圖集第幾列、有哪幾色；兩套 16 色的代表色（色票用）。
- 腳本檢查：數量要是上面那幾個數字；每格都要找到差 0 的那格；不對就停，不要產出半套。
- 代表色怎麼取（建置者決定）：底圖取 `00001000` 每色正中間那點；圖案取一個單色字母圖案的主色。只拿來畫色票，不影響徽章本身。

## 頁面

- 路徑 `/plan/guild`，網頁標題「公會徽章」，副標「挑底圖、圖案和顏色，先看看公會徽章做出來長怎樣。」（候選圖上那句）。
- 加進 `src/lib/site-pages.ts`。導覽列不動。
- 頁面殼照 `src/app/plan/scroll/page.tsx`、`src/app/plan/avatar/page.tsx`：`metadata`＋`<Suspense>` 包讀網址參數的元件。全部在瀏覽器畫，不用後端、不連資料庫（站是 Cloudflare 全靜態）。

### 徽章卡

- 大徽章：底圖那格上面疊圖案那格，放大 8 倍，`image-rendering: pixelated`，棋盤格底。
- 「遊戲裡實際大小」：1 倍的徽章放在一塊深色小底上（像遊戲裡名牌旁邊那樣）。**不寫假公會名**（候選圖上的「楓葉小隊」只是示意，正式版拿掉）。
- 隨機一個：底圖、底圖顏色、圖案分類、圖案、圖案顏色全部隨機（只挑有的顏色）；挑選卡跟著跳到那個分頁、分類。
- 下載：底圖＋圖案畫進 canvas，放大 4 倍（68×68）、透明背景 PNG，檔名「公會徽章.png」。
- 分享：手機用 `navigator.share`，不支援就複製連結，畫面跳「已複製連結」。分享的就是頁面網址（不做預覽圖那種分享頁）。

### 挑選卡

- 分頁「底圖／圖案」，預設底圖。
- 格子顯示的顏色＝現在選的那個顏色（換色票，整排格子跟著換色）；某個圖案沒有這個顏色（`00009026`）就用它唯一那色。
- 選了一個沒有目前顏色的圖案：顏色跳到它有的那色，色票其他顏色變淡不能按。
- 格子不寫名字（遊戲資料裡的名字是韓文，台服沒有中文名），按鈕要有 `aria-label`，寫「底圖 第 N 個」「動物 第 N 個」這類。

### 網址

- 參數：`b`＝底圖編號、`bc`＝底圖顏色、`m`＝圖案編號、`mc`＝圖案顏色，例：`/plan/guild?b=1005&bc=10&m=2000&mc=2`（編號照遊戲 id 去掉前面的 0）。
- 換任何東西都用 `replaceState` 更新網址，不多一筆瀏覽紀錄（`useSearchParams` 要更新的話照 README 的坑：`replaceState` 傳 `null`）。
- 參數不合法（沒有這個 id、顏色超出）就那一項用預設，不報錯。
- 沒參數打開：用預設徽章（建置者決定：候選圖上那個藍條紋底＋橘色老鷹 `b=1005&bc=10&m=2000&mc=2`）。

### 入口

- 紙娃娃頁：放一個連過去的小入口（文字連結或小卡，跟頁面現有的入口長得一致，建置者決定位置）。
- 首頁（11/08 拍板 B）：紙娃娃輪播（`AvatarShowcase`）底下加一行小字連結「做公會徽章」，不多一張卡、不動其他版面；文字連結底線照全站規則用 `--ink-faint`。

## 不做

- 不做公會名牌、角色頭上整排名字的預覽。
- 不寫徽章製作要花多少楓幣（沒查到台服數字，不編）。
- 不存很多個徽章、不做投票、不做分享預覽圖頁。
- 不用 maplestory.io 即時抓圖（只在產生資料時當答案卷用）。
