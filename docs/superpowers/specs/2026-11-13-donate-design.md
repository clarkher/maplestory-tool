# 贊助楓谷幫手（v2.22，11/13 拍板 A）

> 狀態：規劃完成，待另一台電腦實作（金流帳號在那台）。
> 使用者有：**綠界帳號、LINE Pay 帳號**。

## 為什麼做

- 收費方式比較過（11/13）：贊助、付費工具、付費內容。使用者選 **A：先做贊助**。
- 規模誠實估：一天約 206 次造訪 → 每月不重複約 3,000～4,000 人 × 0.2～0.5% 贊助 × NT$100 ≈ **每月 NT$600～2,000**。
  不是要靠它賺大錢，是先把「願意付錢的人有地方付」接起來，順便量轉換率，當以後要不要做付費工具的依據。
- 付費工具（無廣告、雲端存檔、推播）等**一天 1,000 次造訪以上、回訪超過三成**再談，這份不做。

## 硬限制

1. **網站是全靜態（Cloudflare）**，沒有後端收付款通知 → **只用金流的「付款連結」**，不接 API。
2. **repo 不准出現任何金流密鑰**：綠界 MerchantID 以外的 HashKey／HashIV、LINE Pay Channel Secret 都不進 repo、不進前端。
   付款連結本身是公開網址，可以寫在程式裡。
3. **任一條連結是空的 → 那顆按鈕不畫**（跟 AdSense「沒編號不畫」同一套）。兩條都空 → 整個贊助區塊、頁尾連結、/support 頁內容都不出現（/support 頁寫「目前沒有開放贊助」）。
4. 不做：贊助者名單、目標進度條、「已有 N 人贊助」（假社會證明紅線；真的數字也先不放）、彈出視窗、工具頁中間插卡、任何擋內容的設計。
5. UI 不用 emoji、不用 icon set。按鈕字用 `--on-accent`，不寫死白字；不准膠囊形狀（設計系統 A）。
