# 官網影片區（v2.32）設計

## 為什麼
YouTube 頻道「楓谷幫手」開始出片（11/13 起），Shorts 有量、正片沒量。官網要有地方放這些片：
來網站的人多一種看懂工具的方式，片也多一個曝光來源。使用者 11/16：「這一批做完 開始在楓谷幫手官網建立影片區 嵌入 yt 影片」，三題「照你推薦」。

## 拍板（11/16 照推薦 1A 2A 3A）
1. 放哪：新頁 **/videos**；攻略專區（/guides）頁首下面放一排最新短影音＋「看全部影片」；頁尾選單加「影片」。
2. 放哪種：**短影音（直的）一排**、**正片（橫的）一格一格**，分兩區。
3. 名稱：**影片**。

## 做法（我的決定）
- **清單寫在 repo**：`src/lib/videos.ts` 一集一筆（標題、對應工具連結、公開時間、正片 id、短影音 id）。
  不用 YouTube RSS（11/16 實測 feeds/videos.xml 對我們跟 Google 自己的頻道都回 404／500，靠不住）、
  不用 Data API（要把有上傳權限的金鑰放進 Worker，不划算）。
  排程公開的片先寫進來，**頁面在瀏覽器照現在時間篩**，到了公開時間自己出現，不用重新部署。
- **封面自己放**：`public/videos/<id>.webp`（正片 640×360、短影音 360×640），從成片抽。
  點之前不連 Google；點了才換成 `youtube-nocookie.com` 播放器（隱私加強模式）。框的比例先固定，換播放器不跳版面。
- **不放廣告**：/videos 不放 AdSlot（API 稽核草稿寫了「放 YouTube 的頁面不放廣告」）。
- **SEO**：每支片一段 VideoObject JSON-LD（放 body，不放 head）；/videos 加進 site-pages（sitemap、llms.txt）。
- **隱私權政策**：「YouTube 頻道」那段加一句嵌入播放器的說明。

## 不做
- 不在各工具頁嵌自己那一集（使用者選 A 不是 C）。
- 不做留言、按讚數、觀看數（要打 API）。
- 官網公告自動做的片（announce-video 工作流）先不自動進清單：TODO，之後讓工作流上傳後順便開 PR 加一筆。
