# 攻略文互導索引＋延伸閱讀（v2.19）

2026-11-12 使用者看四張候選（A 文末卡片、B 頁首等級條、C 文中順路卡、D 電腦版側欄）回「照推薦」。

## 為什麼

攻略文之間幾乎沒有互相連結：讀完一篇不知道下一篇去哪（留存），Google 也看不到文章之間的關係（內部連結）。

## 拍板

1. **放 A＋B**
   - 職業攻略文（`src/data/job-articles/*.json`）結論框上面放「<職業>這條線」等級條：同一條職業線的每一篇一格，本篇橘框淡底（`OPTION_ON`）、不能點；手機一排放不下就左右滑。
   - 所有攻略文（職業文＋`src/content/guides/*.md`）文末、站內連結那排上面放「看完這篇，接著看」：職業文有下一段就放一張大卡，下面固定 3 張相關文章卡（手機一列一張、左圖右字；電腦三欄、圖上字下）。
   - C（文中段落後插卡）不做：要逐篇挑段落，會動文章內容。
2. **混合挑法**
   - 等級條：自動照職業線接。二轉、三轉文＝一轉那篇＋同一條二轉線（含它的三轉）照等級排；一轉文（10～30）＝自己＋每條二轉線的第一篇，標題改「<一轉>之後走哪條」。
   - 下一段大卡：等級條上本篇的下一格（一轉文沒有，因為下一步是分岔）。
   - 相關 3 張：程式裡一張規則表（`src/lib/guide-related.ts` 的 `RELATED_RULES`），每篇非職業文登記適合的等級範圍、排序、活動結束日。跟本篇等級範圍有重疊的才挑，照排序取 3 張；活動過了結束日自動拿掉（看建置時間）。
   - 手動蓋：`.md` 設定區 `related: /guides/a, /guide`、職業文 JSON `related: [...]`，寫了的排前面，不夠 3 張再自動補。
3. **版面**照候選截圖 A、B。
4. **測試擋**
   - 每篇（職業文＋一般文）相關卡至少 3 張。
   - 相關卡、下一段、等級條、手動 `related` 連到的頁都要存在。
   - 職業線上下段接得起來：每篇二轉、三轉文的等級條都從同系一轉文開始，等級不重疊、照順序。
   - 新的 `.md` 文章或 `GUIDE_PAGES` 頁沒在 `RELATED_RULES` 登記就紅（新文章一定要決定配給哪個等級的人看）。

## 不做

- 不改任何文章內文。
- 不加 GA 事件（之後要量點擊再說）。
- 一般文（.md）沒有等級條（沒有天然的系列）。

- 相關卡標題拿掉開頭的「楓之谷經典版」（同攻略專區卡片的做法），大卡保留完整標題。
