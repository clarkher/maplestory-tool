# 競品功能盤點：他們有、我們沒有（2026-10-29）

查了三類，共約 67 個工具：

- 台服經典版專用：27 個（楓憶、楓錄、波波攻略島、楓探、經典谷圖鑑、楓情報、海馬楓報、楓典、楓股數據……）
- Artale：30 多個（Artale Tools、Artale Kit、夜光掉落網頁、MapleLogs、伊伊經驗小幫手……）
- 海外懷舊版：10 個（NiaMeowDB、Henesys.GG、OSMS Data Explorer、MapleClassic Wiki、Metaroad……）。
  Nexon 的 GMS 經典版 10/21 上線，海外站幾乎都轉去做它了。

「幾家做」是三份報告加起來的約數，同一個站在兩份報告都出現就算兩次（例如楓典、Artale Tools 經典版區）。

## 不建議做

| 功能 | 為什麼不做 |
|---|---|
| 直接搬掉落率 | 楓憶、海馬用的是私服或 v83 的數字，不是這款遊戲的；README「刻意不提供」已寫明 |
| 頻道喊話監聽 | 要讀遊戲封包，違反遊戲條款 |
| 外掛自動檢舉、視窗調整 | 是 Windows 程式，不是網站能做的 |
| 羅茱協作、拉圖斯練習 | 瑪迦提亞、玩具城台服還沒開 |
| 討論區、道具競標 | 要有人管，競標會碰到真錢交易 |

## 注意

- 第 19 項道具行情：10/13 已經拍板「拍賣先做半輔助、先自己用再上站」，要上站得重新拍板。
- 第 1、18、20 項要共用資料（大家看同一份），會寫進資料庫；其他都是只在瀏覽器裡算，沒有線上成本。
- 讀畫面的工具，巴哈有人說收過官方警告信（未證實）；我們現在的截圖版不受影響，即時版（第 2 項）只讀分享出來的畫面、不碰遊戲程式。
